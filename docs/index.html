Build request portal

Build your HyperMOS ROM.

Submit a direct Xiaomi HyperOS 3 China full-ROM link and your Telegram ID. Valid requests are sent to the maintainer for approval before the build workflow starts.

New Build Request

Enter your China ROM link and Telegram ID. The ROM link will be validated again by GitHub Actions before the request is sent for approval.

HTTPS direct ZIP only. HyperMOS supports HyperOS 3 China only. Expected format: codename-ota_full-OS3...CNXM-user-Android-hash.zip.
Enter your numeric Telegram user ID. The HyperMOS bot will send build status and the final ROM download link to this ID. Start the bot first so it can message you.
GitHub sign-in is required to submit a build request. The GitHub request form opens in a new tab, while this tab opens the HyperMOS Telegram bot so you can press Start.

Build engineGitHub Actions
  1. Submit
    Enter a HyperOS 3 China full-ROM URL, Telegram ID, and build options.
  2. Validate & review
    GitHub checks the ROM link, then the maintainer receives a Telegram approval notification.
  3. Dispatch
    The existing HyperMOS build workflow is started automatically.
  4. Result
    The HyperMOS bot sends build status and the final ROM download link to the submitted Telegram ID.
